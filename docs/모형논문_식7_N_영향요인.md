# 모형논문 식 (7): \(N\)에 영향을 미치는 요소

출처: Dillon, McGee, Oseni, *Agricultural Production, Dietary Diversity, and Climate Variability* (World Bank Policy Research Working Paper 7022, 2014). 본문 파일은 `docs/model paper.md`.

식 (7)은 비분리 농업가구모형의 2단계식이다. 종속변수 \(\ln N\)은 수확기 가구 식단다양성의 로그이고, 우변은 \(N\)을 직접 설명하는 변수다. 기후편차와 농업자본은 식 (7)에 들어가지 않고, 내생적인 생산변수 \(Y\)를 통해 \(N\)에 간접적으로만 연결된다.

## 1. \(N\)의 정의

\(N_{hvs}\)는 가구 \(h\), 마을 \(v\), 주 \(s\)의 수확기 식단다양성이다. 소비 모듈의 식품을 FAO 지침(Kennedy, Ballard, Dop 2011)에 따라 12개 식품군으로 나누고, 가구가 소비한 식품군 수를 센다.

논문이 결과표에서 쓰는 12개 군은 곡물·가루, 뿌리·서류, 콩류·견과·종자, 유지, 과일, 채소, 계란, 육류·가금류, 어류·해산물, 유제품, 당류, 조미료·음료다. 표본 평균은 7.55개(표준편차 1.97, \(n=2{,}154\))이다.

식단다양성은 가구 칼로리 가용성의 대리변수다. 가구 내 배분은 균등하지 않으므로 개인 섭취와는 구분된다.

## 2. 식 (7)

\[
\ln N_{hvs} = \beta^{Y} \ln Y_{hvs} + \beta^{pm} p_{m} + \beta^{pv} p_{v} + \beta^{x} X_{vhs} + \lambda_{s} + \varepsilon_{hvs}
\]

\(Y\)는 소비와 동시에 결정되므로 내생적이다. 2단계에서는 식 (6)의 도구변수로 예측한 \(Y\)를 넣는다. 논문의 주 결과는 Table 6(농업수입)과 Table 7(작물군 다양성)의 IV 2단계다. 저자들이 더 신뢰하는 명세는 도구변수 검정을 모두 통과한 Table 6이다.

이론적 출발점은 비분리 수요식 (5)다. 소비는 시장가격, 농산물가격, 임금, 이자율, 농가이윤, 투입재·산출물·자본 가격, 외생소득, 부의 한계효용, 관측·비관측 가구특성에 의존한다. 식 (7)은 이 수요를 식단다양성 지표로 바꾼 실증식이며, 이자율과 가격기대는 주 고정효과 \(\lambda_s\)에 흡수된다고 가정한다.

## 3. 식 (7)에 직접 들어가는 요소

### 3.1 농업생산 \(Y\)

생산은 두 가지로 측정하며, 한 회귀에 하나씩 들어간다. 둘 다 수확 회차에서 계산하고 로그를 취한다.

| 측정 | 정의 | IV 2단계 계수 | 해석 |
| --- | --- | --- | --- |
| 농업수입 | 작물별 수확가치에 대한 농가 추정치의 합. 이윤이 아니라 수입을 쓴다. 가구노동의 잠재가격을 추정하기 어렵기 때문이다. | \(0.18^{***}\) (Table 6) | 수입 10% 증가 시 식단다양성 1.8% 증가. 선호 명세. |
| 작물 생산다양성 | 수확한 식용 작물군 수. 비식용 작물은 제외. 식단 식품군 중 5개 군에 대응. | \(0.24^{*}\) (Table 7) | 작물군 10% 증가 시 식단다양성 2.4% 증가. 1단계 F=7.6으로 약한 도구변수이고, Sargan–Basmann 과잉식별 검정을 통과하지 못한다. |

\(Y\)가 \(N\)에 영향을 주는 경로는 두 가지다. 자가소비에 쓸 수 있는 수확량과, 판매로 생기는 농업소득이다. 농업수입 명세는 작물 선택과 고가 작물로의 전문화를 함께 포함한다.

강건성에서 부호와 크기는 유지된다. 수목작물을 빼면 수입 탄력성은 0.21, 내구재 가액 로그를 추가하면 0.17이다. 작물 개수(군이 아닌 작물 수)로 바꾸면 탄력성은 약 0.21이고, 로그를 벗기면 작물군 1개 추가가 식품군 약 1.05개 추가에 해당한다.

### 3.2 수확기 시장가격 \(p_m\)

수확기 식품 시장가격이다. 식단에 대한 직접 가격효과로 들어가며, 기후충격이 지역가격을 바꿔 소비에 영향을 주는 경로를 식 안에서 통제하는 역할도 한다.

Table 5에 있는 가격은 12개 식품군(곡물·가루, 뿌리·서류, 콩류·견과·종자, 유지, 과일, 채소, 계란, 육류·가금류, 어류, 유제품, 당류, 조미료·음료)의 지역 시장가격이다. Table 6·7은 이 계수 추정치를 지면상 생략한다. 따라서 식품군별 가격이 \(N\)에 미치는 부호와 크기는 본문 표만으로는 확인할 수 없다.

### 3.3 가변투입재 가격 \(p_v\)

비분리 모형에서는 투입재 가격이 이윤을 통해서만이 아니라 소비선택에도 직접 들어간다. 그래서 1단계와 2단계에 모두 포함된다. 모두 로그다.

| 변수 | Table 6 수입 명세 (선호) | Table 7 작물다양성 명세 |
| --- | --- | --- |
| 성인 남성 농업임금 | \(-0.026^{**}\) | \(-0.0027\), 비유의 |
| 비료 kg당 가격 | \(-0.0040\), 비유의 | \(+0.00090\), 비유의 |
| 살충제 kg당 가격 | \(+0.00085\), 비유의 | \(-0.0019\), 비유의 |
| 제초제 kg당 가격 | \(-0.018^{*}\) | \(-0.021^{***}\) |

선호 명세에서 \(N\)과 유의하게 연결된 투입재 가격은 농업임금과 제초제 가격이고, 둘 다 음(−)이다. 비료·살충제 가격은 2단계에서 유의하지 않다.

### 3.4 가구특성 \(X\)

가구 구성과 가구주 특성이다. 논문은 이를 관측된 가구특성 \(\mu\)에 대응시키고, 식품 선호 같은 비관측 특성은 오차항에 남긴다. 단면 자료이므로 가구 고정효과는 없다.

| 변수 | Table 6 수입 명세 (선호) | Table 7 작물다양성 명세 |
| --- | --- | --- |
| 15–65세 가구원 수 | \(-0.010\), 비유의 | \(+0.0040\), 비유의 |
| 0–14세 가구원 수 | \(-0.0014\), 비유의 | \(+0.0065^{**}\) |
| 66세 이상 가구원 수 | \(+0.00047\), 비유의 | \(+0.0078\), 비유의 |
| 남성 가구주 | \(-0.077^{**}\) | \(-0.0017\), 비유의 |
| 가구주 연령 | \(-0.0013^{**}\) | \(-0.0011^{*}\) |
| 가구주 교육연수 | \(+0.0060^{***}\) | \(+0.0055^{***}\) |

두 명세에서 방향이 안정적인 것은 가구주 연령(−)과 교육연수(+)다. 남성 가구주는 수입 명세에서만 식단다양성을 낮추는 쪽으로 유의하다. 0–14세 가구원 수는 작물다양성 명세에서만 양(+)으로 유의하다. 15–65세와 66세 이상은 주 명세 2단계에서 유의하지 않다. 내구재를 넣은 Table 11에서는 15–65세 계수가 \(-0.011^{*}\)로 유의하다.

### 3.5 주 고정효과 \(\lambda_s\)와 오차 \(\varepsilon\)

\(\lambda_s\)는 주 단위 고정효과다. 자료에 없는 이자율, 가격기대, 주 안의 농산물 시장통합을 흡수한다. 농촌 지역끼리는 주 안에서 이 요인들이 비슷하다고 가정한다. 추정 관심 계수는 아니다.

\(\varepsilon_{hvs}\)는 비관측 가구특성(식품 선호 등)과 나머지 교란이다. 표준오차는 enumeration area에서 군집한다.

## 4. \(Y\)를 통해 \(N\)에 간접적으로만 영향을 주는 요소

아래 변수는 식 (6)의 도구변수이고 식 (7)에서는 제외된다. 배제제약이 성립하면 \(N\)에 대한 경로는 생산 \(Y\)뿐이다. 기후가 수확기 가격을 움직여 식단에 직접 영향을 주면 이 제약이 깨지며, 논문은 그 경로를 Table 8에서 따로 점검한다.

식 (6):

\[
\ln Y_{hvs} = \beta^{pv} p_v + \beta^{A} p_A + \beta^{\theta} \theta_{hvs} + \beta^{x} X_{hvs} + \lambda_s + \varepsilon_{hvs}
\]

| 도구변수 | 정의 | 농업수입 1단계 (Table 6) | 작물군 수 1단계 (Table 7) |
| --- | --- | --- | --- |
| 생육도일 편차 | 2010년 파종기(4–6월) 생육도일 − 1981–2009년 평균. 높을수록 고온. | \(-0.0015^{***}\) | \(-0.00014\), 비유의 |
| 강우 편차 | 2010년 파종기 강우 − 2000–2009년 평균. | \(+0.0022^{***}\) | \(+0.0018^{***}\) |
| 생육도일 × 강우 | 두 편차의 상호작용. | \(-0.00001\), 비유의 | \(+0.000017^{**}\) |
| 농업자본 | 농업 자본장비 가치의 로그. 계절 안에서는 준고정 저량. | \(+0.11^{***}\) | \(+0.027^{***}\) |

파종기 고온(생육도일 양(+)의 편차)과 파종기 과소강우는 농업수입을 낮춘다. 강우가 평년보다 많으면 수확 작물군 수도 늘어난다. 생육도일 자체는 작물군 수와 유의하게 연결되지 않고, 강우와의 상호작용만 유의하다. 농업자본은 두 생산변수 모두와 양(+)이다.

자본을 2단계에서 빼는 근거는 시점이다. 자본 투자는 수확기 소비 측정 이전에 이루어지고, 계절 안에 재고가 거의 변하지 않으며, 당기 소비와의 상관도 약하다고 논문은 보고한다.

\(p_v\), \(X\), \(\lambda_s\)는 1단계와 2단계에 모두 있으므로 직접효과와 \(Y\)를 통한 간접효과를 동시에 가진다. 2단계 계수는 \(Y\)를 통제한 뒤의 직접효과다.

## 5. 식 (7) 밖에 두거나 흡수한 이론 변수

수요식 (5)에는 있으나 식 (7)의 추정 계수로 따로 나오지 않는 항목이다.

| 이론 변수 | 식 (7)에서의 처리 |
| --- | --- |
| 농가이윤 \(\pi_t\) | 이윤 대신 관측 가능한 농업수입 \(Y\)를 사용. |
| 이자율 \(r\), 가격기대, 부의 한계효용 \(\lambda_V\) | 주 고정효과에 흡수한다고 가정. |
| 외생소득 \(y_V\) | 주 명세에 없음. Table 11에서 내구재 가액 로그를 추가하면 계수는 \(+0.0068\)로 비유의하고, 수입 탄력성은 0.17로 유지. |
| 토지 | 생산함수의 고정자산이나 식 (7) 우변에는 없음. Table 5의 요약통계(평균 1 ha)로만 제시. |
| 기후 \(\theta\), 농업자본 \(p_A\) | 도구변수. 2단계 제외. |
| 비관측 선호 \(\varepsilon_t\) | 오차항. |
